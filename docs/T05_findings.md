# T05 官方 CSV 匯出與內容摘要實測（完成 2026-09-09）
（原訂題目「個資關閉影像比例」暫緩，優先解決決定專案難度的關鍵未知數；個資問題順延）

## 官方匯出端點（已破解，非爬蟲）
```
GET index.php?act=Archive/export/page/<urlencode(base64(JSON 陣列的記錄ID))>
```
- 記錄ID 來源：檢索結果 HTML 的 `input.result_selecter[value]`
- 回傳：`text/csv; charset=utf-8`（含 BOM），檔名 `NDAP_export_<timestamp>.csv`
- **單次上限 100 筆**（送 600 筆 → 輸出數量=100）
- `Archive/export/result/`（全結果匯出）仍回 HTML 錯誤頁，未解；但有 page 匯出即足夠

**這是系統內建的「下載目錄」功能，使用它不是爬取。**

## CSV 欄位
`no, 資料集, 典藏號, 瀏覽階層, 日期描述, 內容摘要`

## 內容摘要實測（決定性）
有填充，且是有意義的內容。實例：
- 「臺灣省第一屆參議員一覽表（議事錄影像第3～6缺頁）」
- 「黃朝琴議長獻詞」
- 「臺灣省青年團賀電」
- 「向國民政府主席致敬電」
- 「請國府主席迅令中共提出國大代表名單電」

## ⚠️ 關鍵限制：摘要是「件層級描述」，不是全文
長度約 10–25 字，性質等同檔案編目的件名／提要，**不是議事發言的逐字內容**。

### 這對專案的意義（重要轉向）
- ✅ **可行**：件層級的檔案目錄／檢索工具（finding aid）資料集
- ❌ **不可行（除非自己 OCR）**：Parla-CLARIN 全文語料庫

先前規劃的「Parla-CLARIN TEI 編碼的議會語料庫」在沒有 OCR 的前提下**不成立**。
但件層級目錄資料集本身仍是正當且完整的 data paper 標的，且一學期做得完。

## 工作量估算
- 省參議會第一屆 4,085 筆 → 100 筆/次 → **41 次呼叫**，數分鐘可完成
- 全庫 499,341 筆 → 約 5,000 次呼叫（可行但無必要）

## 附帶收穫
摘要內含缺頁註記（如「影像第3～6缺頁」）→ 這是現成的資料品質／缺漏證據，
可直接寫入 data paper 的 quality control 與 limitations 兩節。
