# T11 臺大數位人文研究中心與省議會的關係（完成 2026-09-09）— 省議會軌確定關閉

## 決定性事實
**臺灣大學數位人文研究中心**（digital.ntu.edu.tw）已建置：
1. **地方議會議事錄檢索系統** —— 由臺灣省諮議會統籌、**臺大數位人文研究中心開發**，
   服務 11 個參與地方議會。已上線多個子站：
   kcc / cycc / cyscc / tncc / mcc / hcc .digital.th.gov.tw
2. **「新版臺灣省議會史料總庫」** —— 同中心開發
3. DocuSky 系列平台、歷史地名資訊工具集
4. **主辦 DADH 2025**（數位典藏與數位人文國際研討會，dadh2025.digital.ntu.edu.tw）

## 結論：省議會／地方議會空間由台灣數位人文的旗艦中心完全掌握
加上 T10 發現的 TBDB（師大，含議員傳記）與 twdh 平台（含 CSV 匯出），
這個題材的基礎建設層已被三方覆蓋，且開發者正是該領域的核心機構。

**省議會軌正式關閉為 novelty 標的。**
（史料本身仍可用於分析型研究，但「建置資料集」這個 data paper 命題已不成立。）

## 但有一個重要的正面資訊
臺大數位人文研究中心同時是：
- **DADH 研討會**主辦者
- 《數位典藏與數位人文》相關社群核心

→ 這是這位學生未來**投稿與發表的目標社群**。
研究方向要避開他們已建好的基礎建設，但發表管道正是他們。
