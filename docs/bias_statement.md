## A. 資料已證實的事實（可直接寫入論文）

### A1. 1895–1896 完全空白
**48 張表中，沒有任何一張涵蓋 1895 或 1896 年。**
殖民統治最初兩年沒有留下統計。使用者無法用本資料集討論領臺初期。

### A2. 統計體系的建立過程本身可見（1897–1905）
涵蓋表數：1897 年 6 張 → 1900 年 21 張 → 1905 年 32 張。
**早期年份的資料薄弱，且與後期不可直接比較**——數字上升可能反映
「統計能力擴張」而非「現象本身增加」。**這是最容易誤讀的地方。**

### A3. 穩定期 1906–1940
涵蓋表數穩定在 32–47 張，1928–1939 達到高原（47 張）。
此區間內序列可比性最佳。

### A4. 戰時崩解（決定性發現）
| 年 | 涵蓋表數 |
|---|--:|
| 1940 | 46 |
| 1941 | 43 |
| 1942 | 43 |
| **1943** | **15** |
| 1944 | 14 |
| **1945** | **3** |

**1943 年出現斷崖：從 43 張掉到 15 張（-65%）。**

序列終止年分布：
- **28 / 48 表終止於 1942** ← 最重要的單一結構事實
- 11 表終止於 1944
- 僅 3 表到達 1945

### A5. 序列內部完整
**所有區段都沒有內部缺年。** 缺口全在序列兩端，不在中間 —— 這對時間序列分析是好消息。

⚠️ 先前記載「Welfare_Mt504 缺 1903，為唯一內部缺年」**是錯的**（2026-09-11 更正）。
原書把民國前九年的西元年**誤植為 (1093)**，管線解析不到年份，整列靜默跳過，
造成一個原書並不存在的缺口。現以 `SpecBook.correct_year` 更正為 1903
（依據：1912 − 9 = 1903，前後列為 1902 與 1904），且任何「看起來有年份卻解析不出」
的列標今後都會直接報錯，不再跳過。該年 17 格在原書中本就全是缺值。

## B. 原書序言已回答的問題（2026-09-10 查證，見 D19_preface.md）

### B1. 1943 斷崖的成因 ✅ 已解答
〈編製經過〉明言兩因：
1. **戰時空襲毀損和散失** —— 編纂者須「多方設法搜羅，補其殘缺」
2. **「最近三年來，臺灣因戰事緊張，政局一再改組，許多事業都陷于停頓，
   統計自也不能例外」**

→ 1943–45 稀薄是**統計體系停擺＋空襲毀損**雙重結果，編纂者已盡力追補。

### B2. 編纂主體的立場 ✅ 已解答
- 臺灣省行政長官公署統計室接收前總督府總督官房統計課
- **實際執行者為「留用日人」**，即原殖民地統計官員本人
- **陳儀親自作序**，自承「根據日方資料所編成，其中魚魯豕亥，在所難免」
- 〈編製經過〉政治定性：「他們藉統計的嚴密，以逞壓榨之陰謀。
  是以本書值得作為光復臺灣的一種歷史紀念品。」

→ **接收方指揮、被接收方執行**，政治框架明確。

### B3. 誰不在統計裡 ✅ 部分解答
- 〈凡例〉(三)：**「以有全省性者為限。各縣市別統計數字…未及一一列入。」**
  → 縣市層級被系統性排除
- 日本時代七級機密分類（部分秘・非公表物・取扱注意・部外秘・秘・極秘・軍資秘）
  → **軍事與重要工礦資料在生產階段即排除**
- ✅ **已解答（2026-09-10，見 D20_notes.md）**：
  - **Mt481 附註(2)：「民國十年度以前不包括高山族學齡兒童」**
    → 1921 年前學齡人口不含原住民，跨年就學率計算必須處理此斷點
  - **Mt479**：山地教育所「由警務局會同文教局主持，**教員則以警察兼充**」，
    修業年限四年（1943 起才六年），原書自稱「帶有岐視性質之教育」
    → 原住民**在資料中，但屬警察系統下的獨立不對等體系**，不可與國民學校直接合併

### B4. 分類變動 ✅ 已解答（且驗證了本資料集的處理方式）
〈凡例〉(七)：「歷年事態變遷過鉅，統計項目前後極不一致…
**其不應予以併合，則割為數段分列之**。」
→ 多區段結構是編纂者的刻意設計。本資料集的 `section` 欄正對應此設計。
- ⚠️ **有現成處理方案可循**：古慧雯〈日治時期台灣的犯罪統計〉(2011) 指出
  台灣於 **1898、1899、1901、1909、1920** 年五度重劃行政區，
  其作法為將 1920 年後之 5 州 2 廳簡化為 5 區（台北・新竹・台中・南部・東部），
  並將 1920 年前各區劃併入同一組。本資料集若需地理比較可沿用或對照此方案。

### B5. 年度與曆年 ✅ 已解答
〈凡例〉(十二)：年度＝4/1–翌年3/31；年度底＝翌年3/31；年底＝12/31。

## B'. 新增的涵蓋性事實（來自〈編製經過〉）

### 兩層選擇性
- 來源 **1,207 種**統計書刊 → 初選 **2,000 餘表** → 最終收錄 **540 表**
- 本資料集處理 48 表 ≈ 全書 **9%**
→ **使用者面對的是經過兩次篩選的資料**，須明確說明。

### B6. 全書紀年已被改寫為民國紀年 ✅ 已查證（2026-09-10）
全書 **45,691 個非空白儲存格中，沒有任何一格出現明治、大正或昭和**
（實測，見 `scripts/second_corpus.py` 與 `docs/W05_generalisation.md`）。

日治五十年的統計原以日本年號紀年。1946 年編纂時**全部改寫為民國紀年**，
1912 年以前寫作「民國前 N 年」，並在括號內附西元年（占可辨識年份列標的 98.2%）。

→ 這是接收方在**每一頁**上執行的編輯行為，且在 tidy 資料中完全看不見痕跡。
　 使用者若要與日治時期原始統計書（如《臺灣總督府統計書》）對照，
　 必須知道兩者紀年系統已不同，且本書的年份是**轉換後**的結果。
→ 換算本身可驗證：民國前 N = 1912 − N、民國 N = 1911 + N，
　 在 117 筆同時具有年號數字與括號西元年的列標上**全數相符**。

### B7. Mt487-2 與 Mt489 的死亡數 ✅ 已修正（2026-09-11）
這兩張表在列標內用 `┌患者`／`└死亡` 把每一年拆成兩列，**只有患者那一列帶年份**。
先前的擷取以年份定位資料列，**死亡列整列被跳過，1,895 個數字未進入資料集**，
留下來的只有患者數，而 schema 沒有任何欄位說明這件事。

現已修正：第二列沿用上一列的年份，「患者」「死亡」寫入 `dim2`（見 CODEBOOK §2a）。
`Mt487-2 / 傷寒 / 1931` 現在有兩列：患者 762、死亡 154，皆與原始檔一致。
→ **舊版資料的使用者注意**：v0.4 以前這兩張表的數字全是患者數。

### 數位化階段的資訊遺失
原書以「－」（未調查）與「…」（數字不明）區分兩種缺值；
**中研院 2006 年數位化已一併轉為「.」**，語意無法還原。
→ 此為**數位化造成**，非原書缺陷。欲區分者須回查原書。
