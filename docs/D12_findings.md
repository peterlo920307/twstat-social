## 自動修復嘗試（依最底層表頭重複週期切段，再串接上層字元）
原理：原表把標籤字元散置於其欄位跨距的頭尾，跨距邊界應可由
最底層表頭的循環（共計／本省人／日本人／其他）推得。

**結果：失敗，且是危險的失敗。**
表面上「無單字元標籤」的比例從 4/16 升到 12/16，但**逐項檢視後多數是錯的**：
| 表 | 產出 | 判定 |
|---|---|---|
| Mt468 | 大學／專門學校／師範學校／中等學校(2)／職業學校(3)／國民學校 | ✅ 正確 |
| Mt483 | 盲者／聾啞者／盲聾啞者 | ✅ 正確 |
| Mt470 | 教員／**學生年度中學生異動** | ❌ 兩個標籤被併成一個 |
| Mt472 | 教員／學尋常科／**生年度中學生異動高等科入學畢業** | ❌ |
| Mt474 | **教總計**／男／**員女** | ❌ 跨層錯接 |
| Mt482 | **表482歷年各種學校學生投考人數及入學人數台入學入學佔投** | ❌ 表題被吸入 |

### 方法論教訓（應寫入 data paper 的 Quality Control）
1. 「無單字元標籤」是**不良的正確性代理指標**——多字元標籤同樣可能是錯的
2. 自動重建產生的是**看似合理但實際錯誤**的標籤，比明顯壞掉更危險，
   因為沒有任何自動化檢查抓得到
3. → **這正是本資料集必須逐表人工指定的理由**，不是效率問題而是正確性問題

## 改採方案：人工填表
`docs/header_worksheet.csv` —— 每一欄位一列，已預先填好可機器判定的部分：
| 欄位 | 內容 |
|---|---|
| `file` / `col` | 檔名與欄號 |
| `bottom_label` | 最底層表頭（機器已正確擷取） |
| `upper_fragments` | 上層的散置字元（供人判讀用） |
| **`CORRECT_dim1`** | **待人工填寫** |
| `CORRECT_dim2` | 已預填 bottom_label，可覆寫 |
| `note` | 備註 |

規模：**全部 845 列**（教育類 296 列）；
其中需人工判斷者 540 列，**不同的 (檔案, 碎片) 組合 434 組**。
試算表可用複製填滿，實際判斷次數遠少於列數。

→ 工作量從「讀 50 份試算表自行寫規格」降為「填一欄」。
**修正先前估計：教育 17 表約 2–4 小時，而非 25–50 小時。**

## 交付

  **只處理已填寫的表，未填者跳過並列出**，不會靜默產生錯誤標籤
