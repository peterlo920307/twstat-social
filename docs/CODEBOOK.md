## 2. 缺值與旗標定義（依原書〈編製凡例〉(十一)）

原書官方定義：
> 「－」表示**未調查或無數字**，「…」表示**數字不明**，「0」表示**有數不及一單位**。

| flag | 原表樣態 | 意義 | 筆數 |
|---|---|---|--:|
| `missing` | `.` | 缺值。**注意**：中研院 2006 年數位化時已將原書的「－」與「…」**一併轉為「.」**，兩種缺值的語意無法還原 | 7,555 |
| `less_than_one_unit` | `0` | **有數不及一單位，非零** | 1 |
| `blank` | （空白） | 原始儲存格什麼都沒有，原書未印任何記號。與 `.` 是不同的證據，常見於當年尚不存在的類別 | 709 |
| `covered` | （空白，位於括弧值右側） | 被左側的括弧值跨過的欄。**該括弧值是它自己那欄加上右側所有 `covered` 欄的合計**，各欄不可單獨解讀 | 246 |
| `bracket_artifact` | `└─N─┘`、`┌─N─┐`、`└──N──┘` 等 | 跨欄合併值的排版括弧，數值已抽出。若右側同列有 `covered`，此值為合計 | 131 |
| （空） | 數字 | 一般數值 | 30,508 |

`non_numeric`（純文字儲存格）不會進入 tidy 檔；該旗標只出現在 `twstat.values`
的解析結果中。

> **v0.1 → v0.2 的兩項變動**
> `missing_dot` 更名為 `missing`。
> `bracket_artifact` 由 16 筆增為 108 筆：原本的括弧樣式只認得 `└─N─┘` 一種寫法，
> 排版上同樣的括弧也寫作 `┌─N─┐`、`└──N──┘`、`└───────N───────┘`，
> 這些數字先前被當成非數值丟棄。修正後**救回 98 個數值**、檔案增加 102 列，
> 既有數值一個都沒有改變。詳見 `W06_layout.md`。

⚠️ **三個容易踩的陷阱**
1. **`missing`、`blank`、`covered` 皆不得填補為 0。** 尤其 `covered` 的數值已含在左側括弧值中，填 0 或另行估計都會重複或錯算。
2. **`less_than_one_unit` 的 value 雖為 0.0，但不是零**，而是左設限觀察值
   （小於一個單位）。直接計算平均會低估。
3. **這條規則有表格層級的例外。** 表 491 是法定傳染病**死亡率**，
   其附註(1)明言「記有「０」號之各欄表示有患者而無死亡者」，
   該表的 46 個 0 因此是**確值零**，旗標為空。
   原書的一般規則（〈凡例〉(十一)）與個別表格附註衝突時，以附註為準。

## 2a. 取自列標的第二維度
表 487-2 與 489（民國二十年以後各區段）把每一年拆成兩列，以括弧畫在列標欄：

```
民國  二  十年(1931)┌患者   17025  762 …
                   └死亡    1326  154 …
```

只有第一列印年份。擷取時第二列沿用上一列的年份，列標上的「患者」「死亡」寫入 `dim2`。
這兩張表原本的 `dim2` 刻意留空，因此不需要新增欄位。若某欄本身已有 `dim2`，
兩者以「·」連接（如 `本省人·患者`）。**使用這兩張表時務必依 `dim2` 分開患者與死亡。**

## 2a-2. 由數位化者計算的比率欄
表 480、481、482 共 **21 個比率欄**（「學齡兒童每百人中就學中數」「入學佔投考百分比」
「開館一日平均閱覽人數」）的數值帶有完整的浮點精度，例如 `13.144225880675714`。

**這些不是原書印出的數字。** 原書最多印到小數兩位；481 個全精度數值
**全部**等於同一列另外兩格的比值（或其 100 倍），誤差小於 10⁻⁹。
它們是 2006 年數位化時在試算表中計算出來的。

本資料集如實保留試算表的內容（`verify` 以此核對），但使用者應注意：
- 這些欄是**衍生值**，可由同列的分子、分母重算，不是獨立觀察
- 引用時應四捨五入到原書的精度，不應呈現 16 位有效數字
- 若與原書對照有差異，以原書印出者為準

## 2b. 期間型態定義（依原書〈編製凡例〉(十二)）
> 年度指每年**四月一日至翌年三月三十一日**；年度底為**翌年三月三十一日**；
> 年底則為**每年十二月三十一日**。

| period_type | 原文 | 定義 |
|---|---|---|
| `calendar_year` | 年 | 曆年 |
| `year_end` | 年底 | 12/31 |
| `fiscal_year` | 年度 | 4/1–翌年 3/31 |
| `fiscal_year_end` | 年度底 | 翌年 3/31 |
| `academic_year` | 學年 | 學年制 |

**不可混用。** 曆年僅佔 40.7%；年度基準（`fiscal_year` + `fiscal_year_end`）
36.7%，年底 22.5%。**非曆年者合計 59.3%。**

## 2c. 單位（〈凡例〉(十)）
貨幣一律臺幣；度量衡折為標準制；特殊情形原書於附註欄註明折合率。

## 2d. 附註：從標籤上的 (1) 找到說明
標籤常帶原書的註腳編號，例如 `dim2 = 閱覽人數(1)`、`section_label = 民國二十年至三十一年(2)`。
對應的說明在兩個檔案裡：

- `data/notes.csv`：每條附註或材料來源一列，原文照錄（102 列）
- `data/note_items.csv`：把附註拆成編號項，每項一列（93 列），欄位
  `table_id`、`section_label`、`marker`、`text`、`src_row`

**連結鍵是 `table_id` + `section_label` + 編號**，不是區段編號。
附註依印刷頁擺放，不依表的結構：表 487-2 唯一的附註印在五個表頭帶中第一個的下方，
但適用於全部五個；它們共用同一個區段標題，所以用標題連結才對得上。

```python
import re, pandas as pd
tidy = pd.read_csv("data/tidy.csv")
items = pd.read_csv("data/note_items.csv")
tidy["marker"] = tidy["dim2"].str.extract(r"[(（](\d{1,2})[)）]")[0].astype("Int64")
linked = tidy.merge(items, on=["table_id", "section_label", "marker"], how="left")
```

資料集中所有標籤上的編號（57 個不同標籤）**都能對到說明**，由
`tests/test_published_data.py` 檢查。
