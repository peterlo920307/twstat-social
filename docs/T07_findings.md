# T07 文獻館引用與再利用規範（完成 2026-09-09）— 未能取得，風險升高

## 實查結果：查不到正式的資料開放宣告
- th.gov.tw 首頁為 JS 模板渲染（`{{item.Name}}`），134 個連結中**無任何**「資料開放宣告 /
  著作權 / 版權 / 授權」頁面連結
- drtpa.th.gov.tw 的 Landing/helper 亦無授權說明
- 網路搜尋亦未找到文獻館的「政府網站資料開放宣告」頁

## 唯一可見的權利敘述（drtpa 站上）
> 「本館僅提供系統數位圖檔閱覽服務，臺灣省議會史料實體檔案移交國家發展委員會檔案管理局；
> 地方議會議事錄屬各地方議會所有，若需申請授權者，請逕洽原件典藏單位。」

**語意偏限制，且只談影像與實體檔案，未涵蓋 metadata／內容摘要的再利用。**

## 旁證（不足以據以行動）
- 台灣多數 .gov.tw 網站採「**政府資料開放授權條款第1版**」（OGDL v1.0）：
  可重製、修改、公開傳輸、**得為商業利用**，非專屬、免授權金、無時地限制，僅需標示來源
  → 與 CC BY 相容。但**無法確認文獻館採用此條款**。
- 國家文化記憶庫有明示的〈資料授權規範〉並以創用CC標示，惟其自承
  「早期各機關多以著作權法註記，多數資料暫無法以創用CC分類」；
  且未發現省議會史料收錄於該平台。

## 結論
**T07 未能解除 T06 的風險，反而確認了它。**
在無公開授權聲明的情況下，把 `內容摘要` 納入公開發布的資料集有實質法律不確定性，
而 JOHD 要求開放授權 + DOI 存放，這是硬性門檻。

## 剩下的選項（與 T06 相同，但現在更明確）
1. 去信 archivesservice@mail.th.gov.tw 詢問 metadata 再利用條件（成本：一封信）
2. 只發布事實欄位，捨棄內容摘要（安全，但資料集價值大減）
3. 放棄省議會方向

## ⚠️ 對整體方向的警訊
累積至此的兩個發現——
(a) 摘要是件層級描述、非全文（T05）
(b) 權利狀態無法自行釐清（T06、T07）
——共同指向：**省議會方向的天花板比原先評估的低。**
建議在繼續往下跑 T08 之後的任務前，先與使用者確認是否維持此方向。
