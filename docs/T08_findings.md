## 為什麼這是重大發現

**1. 這是現成的 Parla-CLARIN speaker 權威檔**
穩定 ID + 姓名 + 生卒年 + 跨機關任職史，正是議會語料庫最難自建的那一塊。

**2. 權利狀態明顯優於內容摘要**
記錄自帶 `_view: 開放`、`_flag_open: 1`、`_flag_privacy: 0`。
這不是授權條款，但**是檔案館自身的開放性標記**，證據強度遠高於 T06/T07 的空白。
且傳記附有完整參考文獻，可回溯至已出版來源。

**3. 它本身就足以構成一個完整專案**
369 位議員、1946–1998，涵蓋戒嚴時期台灣**整個民選政治階層**：
李萬居、郭雨新（黨外先驅）、許世賢（戰後首位女性市長）、吳三連。
- 規模小（369 筆）→ 一學期綽綽有餘
- 已是結構化 JSON → 無需 OCR、無需解析影像
- **集體傳記（prosopography）是 JOHD 明確收錄的文類**，比「檔案目錄」更貼近人文資料集

## 對整體方向的影響（建議轉向）
先前兩個壞消息（摘要非全文、目錄權利未明）打擊的是「議事錄目錄」方向。
**議員傳記不受這兩個問題影響**：它是全文、是結構化 JSON、且自帶開放標記。

→ **建議把專案主體從「議事錄目錄資料集」改為「臺灣省議會議員集體傳記資料集
（1946–1998）」**，議事錄目錄降為選配的第二層。
