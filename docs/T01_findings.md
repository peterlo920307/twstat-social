# T01 省議會史料總庫檢索介面（完成 2026-09-09）

## 存取方式（實測可行，無需帳號）
1. 取得訪客 session：`POST https://drtpa.th.gov.tw/index.php?act=Landing/guest`（回 PHPSESSID）
2. 檢索：`GET index.php?act=Archive/Search/<urlencode(base64(JSON))>`
   JSON（必須 compact，無空格）：`{"query":[{"field":"collection","value":"001-01-01OA-00","attr":"+"}]}`
3. 已驗證欄位：collection（成功，回 388 筆）、meeting_level、serial、zong
4. 分頁 20/50/100；排序：資料類型/目次/典藏號/日期描述

## 可檢索欄位（15）
全欄位、典藏號、會議階層、類別階層、題名、日期描述、內容摘要、
主席、主要議員、相關文號、參照資料、相關人員、相關組織、相關地點、相關主題

## 官方規模（系統自述）
總計 6 大類、499,341 筆
- 檔案 98,795（1946–1998）
- 議事錄 121,863（1946–1998）
- 公報 227,987（1959–1998）
- 議員小傳&前傳 **369 位議員**
- 照片、議事影音
分面：質詢 11,143 / 提案 31,174 / 總務 17,888 / 民政 10,464 / 經建 14,218 / 財政 7,979 / 教育 1,272 / 主計 3,892
會議 397,892（省參議會 4,085 / 臨時省議會 24,424 / 省議會 369,383）
年代逐年統計 1946–1998 可取得

## 關鍵發現
- **369 位議員傳記 = 現成的 speaker 權威檔**（Parla-CLARIN 必需品）
- **質詢 11,143 筆**，年代 1946–1998（立法院那批是 11,671 筆但只有 2012 起）
- **有「內容摘要」欄位** → 可能不需 OCR 就有機器可讀文字
- 具權威控制的編目（人員/組織/地點/主題）
- 系統由臺灣大學數位人文研究中心建構
