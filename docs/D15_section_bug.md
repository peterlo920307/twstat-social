# D15 重大錯誤：未偵測區段，已修正（2026-09-10）

## 錯誤內容
原表常將**多個機構／族群／期間垂直堆疊於同一檔**，各區段有獨立表頭。
先前的管線只找「第一個年份列」並一路處理到檔尾，
**把不同對象的數字混成同一條序列**。

掃描結果：50 張表中 **11 張為多區段**。
其中 **7 張已被我回報為「完成」**：

| 表 | 實際區段 |
|---|---|
| Edu_Mt470 | 4 段：臺中農林／臺南工業／臺北經濟／帝大附屬醫專 |
| Edu_Mt472 | 4 段：臺北高校／帝大預科／中學校／高等女學校 |

| **Edu_Mt481** | **2 段：本省人／日本人** |
| **Edu_Mt483** | **2 段：本省人／日本人** |
| Hygiene_Mt488 | 2 段：民國前7–19年／民國20–31年（疾病分類不同） |

**Mt481／Mt483 尤其嚴重：本省人與日本人被混為同一序列，族群差異消失。**

## 為什麼沒被抓到
`auto_verify()` 比對的是**數值與原始儲存格是否相符** —— 全部相符。
錯的是**語意歸屬**：第 2 段的列被套上第 1 段的標籤。
**這類錯誤沒有任何自動檢查抓得到**，只能靠結構稽核發現。

## 額外發現：區段間欄位配置可能位移

→ 即使同一檔案，也不能假設各區段欄位對齊。
