# 人工驗證與標註者間一致性方案

## 關鍵設計決定：把驗證拆成兩層
先前假設「需要抽樣人工比對所有東西」。實際檢視後，**兩層性質不同，
只有第二層需要人力**——這大幅降低了工作量。

### 第一層：數值轉錄正確性 → **100% 自動全檢，不需人工**
每筆 tidy 紀錄都帶 `src_row`/`src_col`，可直接回讀原始 .xls 儲存格比對。
→ 這不是抽樣估計，是**全量核對**，可報告「N 筆中 M 筆不符」的確切數字。
→ 由 `scripts/make_validation_sample.py` 的 `auto_verify()` 執行。

**這比抽樣更強**：JOHD 審查人看到的是完整核對，不是信賴區間。

### 第二層：維度語意標註 → **必須兩位人類獨立編碼**
`dim1`/`dim2` 是「這個數字在講什麼」的判斷。
表頭字元散置（實測 78% 自動正確率）代表機器重建會出錯，
且錯誤無法自動偵測——只有讀得懂原表版面的人能判斷。
→ **這是 Cohen's κ 適用的地方，也是無法壓縮的人力。**

## 抽樣設計
- **母體**：完成 tidy 化後、`dim1` 非空的所有紀錄
- **方法**：依 `table_id` 分層，每表等額抽取
- **樣本數**：**n = 200**（涵蓋全部 50 表，每表約 4 筆）
- **亂數種子**：20260909（固定，確保可複現）
- **程序**：
  1. 產生空白編碼表（含 table_id / src_row / src_col / year / value）
  2. **複製兩份**，兩位標註者**各自獨立**填寫 `coder_dim1`/`coder_dim2`，
     過程中**不得互相參照**
  3. 兩人皆對照**原始 .xls 版面**判讀，不看管線輸出
  4. 計算 κ；同時比對管線輸出得出自動化正確率

## 判讀標準（需在編碼前共同議定並寫入 codebook）
- 表頭字元散置時，以**原書排版意圖**為準（如「大」「學」分置兩欄 → 「大學」）
- 上層表頭缺漏時，向左最近的非空標題前向填補
- 無法判定者填 `UNCLEAR`，不猜測

## 報告方式
- Cohen's κ 值與 95% 信賴區間
- 分歧案例的類型歸納（寫入 limitations）
- 自動化管線相對於人工共識的正確率

## 找第二位標註者
**這是實際上的關鍵路徑**。建議：同課程同學互相擔任對方專案的第二標註者。
200 筆的判讀工作量約 2–3 小時。

## 交付
- `scripts/make_validation_sample.py`
  - `auto_verify(tidy_csv, xls_dir)` → 第一層全檢
  - `draw_sample(tidy_csv, n=200, seed=20260909)` → 產生編碼表
  - `kappa(a, b)` → Cohen's κ
