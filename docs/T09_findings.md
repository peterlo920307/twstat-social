# T09 議員傳記列舉可行性（完成 2026-09-09）
（原訂「既有數位人文研究查核」順延至下一輪；本輪優先解決決定新方向成立與否的列舉問題）

## 結論：可以列舉 ✅

### 行不通的路
- `mbrapp` **不接受 mbrno**（TPAM0001 → action=0）；只吃姓名
- 無專用名錄端點：`Archive/mbrlist` 等未知 act 會落回預設檢索頁（297KB 的一般結果頁）

### 行得通的路
檢索請求的 JSON 除了 `query`，還有第二個頂層鍵 **`zselect`**（資料集選擇）：
```json
{"query":[...], "zselect":["biography"]}
```
送出後，結果頁會渲染 **`<persona>姓名</persona>`** 標籤。
實測取得：賴樹旺、賴榮木、王安順、廖秉輝、陳火土、李秋遠、許新枝、陳新發、
吳泉洝、鄭大洽、章博隆、黃國政…

**完整流程**：`zselect:["biography"]` 分頁掃描 → 收集所有 `<persona>` 姓名
→ 逐一呼叫 `Archive/mbrapp/<姓名>` 取得 JSON 傳記 → 369 筆完成。
